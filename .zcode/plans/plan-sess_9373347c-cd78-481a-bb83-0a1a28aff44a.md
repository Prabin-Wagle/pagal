# Fix mobile lag: theme-change stutter + animation jank

## Root causes
1. `.grain` overlay: 200%×200% fixed layer + `mix-blend-mode: overlay` + infinite animation → constant full-screen re-blending on mobile GPUs (both complaints).
2. Theme flip: only `body` background fades 0.9s while `--fg/--muted/--line` snap instantly → "shutter" mismatch; unregistered custom properties can't transition.
3. `will-change: transform` on every SplitText `.char` → permanent compositor layers.
4. Hero scrub animates `letterSpacing` (layout/reflow per scroll frame).
5. Capabilities animates `font-variation-settings` (text re-shape per frame on tap).
6. Projects DrawSVG is scroll-scrubbed on mobile (SVG repaint every scroll frame).

Desktop look stays untouched (user says it's perfect) — all heavy changes are gated to touch/coarse pointers.

## Changes

### 1. `src/index.css` — grain + theme crossfade (main fix)
- `@media (pointer: coarse)`: grain becomes **static texture** — `animation: none`, `mix-blend-mode: normal`, `inset: 0; width/height: 100%` (no more 4× viewport layer, no blend, no perpetual re-composite). Desktop keeps the animated blended grain.
- Register theme vars so the whole page crossfades in sync:
  ```css
  @property --bg { syntax: "<color>"; inherits: true; initial-value: #0b0a09; }
  @property --fg { syntax: "<color>"; inherits: true; initial-value: #ece6d8; }
  @property --muted { syntax: "<color>"; inherits: true; initial-value: #8b8474; }
  @property --line { syntax: "<color>"; inherits: true; initial-value: rgba(236,230,216,0.14); }
  ```
- Replace body's `transition: background-color .9s, color .9s` with `transition: --bg .7s, --fg .7s, --muted .7s, --line .7s` (ease-in-out-quart) → background, text, and hairlines all fade together; no half-flipped state.
- `@media (pointer: coarse)`: shorten to ~0.4s (smaller repaint window).
- Fallback: browsers without `@property` just snap instantly (harmless).

### 2. `src/index.css` — `.char` layers
Remove `will-change: transform` from `.char` (GSAP promotes layers during tweens automatically; permanent promotion of every character is a net loss on mobile).

### 3. `src/components/sections/Hero.tsx`
Drop `letterSpacing: "0.02em"` from the scroll-scrubbed exit tween (keeps the `xPercent` drift — visually near-identical, no per-frame reflow).

### 4. `src/components/sections/Capabilities.tsx` + `index.css`
Add a `.vf-anim` utility: transitions `font-variation-settings`/`letter-spacing` only inside `@media (hover: hover) and (pointer: fine)`; on touch, weight/color change instantly (no 700ms text reshaping). Swap the Tailwind `transition-[font-variation-settings,...]` class for `.vf-anim`.

### 5. `src/components/sections/Projects.tsx`
Use `gsap.matchMedia()`: desktop keeps the scrubbed DrawSVG timeline; on `(pointer: coarse)` the draw/pops/labels timeline plays **once** when the visual enters the viewport (no per-scroll-frame SVG repaint).

### 6. `src/components/sections/Philosophy.tsx` (small tune)
On coarse pointers, shorten the pinned scrub distance (`+=220%` → `+=150%`) — less time in the most expensive pinned state on mobile; desktop unchanged.
